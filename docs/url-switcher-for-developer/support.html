URL Switcher for Developer

環境URLの登録や切替でお困りの場合は、以下をご確認ください。

よくある質問

現在のURLがプロジェクトに一致しません

環境として登録したURLのドメインとパスを確認してください。本拡張機能は http:// と https:// のページに対応し、Chromeの設定画面などの特殊なURLでは動作しません。

切替後にパスやクエリを維持したいです

登録した環境URLのパスを基準に、現在のページの後続パス、クエリ、ハッシュを切替先に引き継ぎます。登録URLのパスを確認してください。

右クリックメニューが表示されません

オプション画面で右クリックメニューが有効になっていることを確認してください。設定を変更した後、対象のページを再読み込みしてください。

プロジェクトをバックアップできますか？

オプション画面からプロジェクト設定をYAML形式でエクスポートできます。復元する際は、同じ画面からファイルをインポートしてください。

データの取り扱い

現在のタブURLは端末内で照合し、プロジェクトと環境の設定はChrome内に保存します。これらの情報は開発者のサーバーへ送信しません。詳しくはプライバシーポリシーをご覧ください。

お問い合わせ

解決しない場合はGitHub Issuesからご連絡ください。

Frequently asked questions

The current URL does not match a project

Check the domain and path of the environment URL you registered. The Extension works on http:// and https:// pages. It cannot work on special URLs such as Chrome settings pages.

Can I preserve the path and query when switching?

The Extension uses the path in the registered environment URL as its base, then carries the remaining page path, query, and hash to the target. Check the path in your registered URL.

The right-click menu is missing

Check that the context menu is enabled on the Options page. Reload the page after changing the setting.

Can I back up my projects?

Use the Options page to export project settings as a YAML file. Import the file from the same page to restore it.

Data handling

The current tab URL is matched on your device, and project settings are stored in Chrome. The Extension does not send this information to a developer-operated server. See the Privacy Policy for details.
