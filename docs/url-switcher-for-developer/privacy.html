URL Switcher for Developer

最終更新日: 2026年10月6日

URL Switcher for Developer（以下「本拡張機能」）は、登録した本番・開発・ローカルなどの環境URLを切り替えるChrome拡張機能です。本ポリシーでは、本拡張機能が処理する情報とその取り扱いを説明します。

処理する情報と目的

本拡張機能は、環境切替と現在の環境表示のため、Chromeの現在のタブURLを一時的に読み取り、端末内で登録済みURLと照合します。切替時には、ページのパス、クエリ、ハッシュを切替先URLに引き継ぐために使用します。閲覧履歴を取得したり、ページ本文、フォーム入力、Cookieを読み取ったりしません。

ユーザーが入力したプロジェクト名、環境名、環境URL、色、言語などの設定は、Chromeのローカルストレージに保存します。現在のタブURLは環境判定のために一時的に処理し、ユーザーがそのURLをプロジェクト設定として保存しない限り、設定データとして保存しません。

保存、共有、送信

本拡張機能は、現在のタブURLやプロジェクト設定を開発者のサーバーへアップロードしません。環境を切り替えると、Chromeがユーザーの選択した移動先URLを通常のページリクエストとして開きます。その際、移動先サイトにはURLのパスやクエリが送信される場合があります。広告、分析、追跡には使用しません。プロジェクト設定のエクスポートは、ユーザーが操作した場合にYAMLファイルとして端末に作成します。インポートもユーザーが選択したファイルを端末内で読み込みます。

URLにはパスやクエリに個人情報や認証用の値が含まれる場合があります。環境URLを登録する際は、パスワード、アクセストークンなどの秘密情報を含めないでください。

権限の使用

  • storage: プロジェクト、環境URL、表示設定をChrome内に保存し、次回利用時に復元します。
  • tabs: 現在のタブURLを読み取って環境を照合し、選択された環境へ移動します。
  • contextMenus: 現在のURLに応じた環境切替やプロジェクト管理の右クリックメニューを表示します。

保存期間と削除

プロジェクトと設定は、ユーザーが本拡張機能内で削除するまでChromeのローカルストレージに保存されます。Chromeから本拡張機能をアンインストールすると、関連するローカルデータはChromeの管理に従って削除されます。エクスポートしたファイルはユーザーが管理し、不要になった場合は端末から削除できます。

Chrome Web Store User Data Policy

本拡張機能は、Chrome Web Store User Data Policy の Limited Use 要件を含む規定に従います。データは環境切替という単一用途の提供に必要な範囲でのみ使用し、広告、信用力の評価、融資には使用しません。許可された目的を除き、第三者へ転送または販売しません。

機能や法令の変更に応じて本ポリシーを更新する場合があります。更新内容と日付はこのページに掲載します。

Privacy Policy

URL Switcher for Developer

Last updated: October 6, 2026

URL Switcher for Developer (the “Extension”) switches between saved production, development, and local environment URLs. This policy explains what information the Extension processes and how it is handled.

Information processed and purpose

To match an environment and show the current environment, the Extension temporarily reads the current tab URL and compares it with saved URLs on your device. When you switch environments, it carries the page path, query, and hash to the target URL. It does not collect browsing history or read page contents, form inputs, or cookies.

Project names, environment names and URLs, colors, language, and other settings that you enter are stored in Chrome local storage. The current tab URL is processed temporarily to identify an environment and is not saved as a setting unless you choose to save it in a project.

Storage, sharing, and transmission

The Extension does not upload the current tab URL or project settings to a developer-operated server. When you switch environments, Chrome opens the destination URL you selected as a normal page request. The destination site may receive the URL path and query as part of that request. The Extension does not use data for advertising, analytics, or tracking. When you choose to export your project settings, a YAML file is created on your device. Import reads a file that you select, locally on your device.

URLs can contain personal information or authentication values in their paths or query strings. Do not save passwords, access tokens, or other secrets in environment URLs.

Permissions

  • storage: Stores and restores projects, environment URLs, and display settings in Chrome.
  • tabs: Reads the current tab URL to match an environment and navigates to the environment you select.
  • contextMenus: Shows environment switching and project management options in the right-click menu for the current URL.

Retention and deletion

Projects and settings remain in Chrome local storage until you remove them in the Extension. When you uninstall the Extension from Chrome, its local data is removed according to Chrome's data management. You manage exported files and can delete them from your device at any time.

Chrome Web Store User Data Policy

The Extension complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only as necessary to provide the Extension's single purpose of switching environments. It is not used for advertising, creditworthiness, or lending, and is not transferred or sold to third parties except as permitted by the policy.

Changes to this policy

This policy may be updated when features or legal requirements change. Updates and their dates will be posted on this page.
