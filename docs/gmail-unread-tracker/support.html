Gmail Unread Tracker

Gmailの未読件数が表示されない場合は、以下をご確認ください。

よくある質問

アカウントが一覧に表示されません

Chromeで対象アカウントにログインした状態でGmailを開き、サイドバーの「拡張機能で追跡」を押してください。その後、オプション画面の「今すぐ再取得」を実行します。

バッジに「!」が表示される、または未読数が更新されません

Gmailにログインしていることを確認し、オプション画面で「今すぐ再取得」を実行してください。取得間隔は1、5、15、30、60分から選べます。問題が続く場合は、オプション画面の「デバッグ情報」を確認してください。

追跡をやめるにはどうすればよいですか

オプション画面で対象アカウントを削除してください。拡張機能をアンインストールすると、以後の処理は停止します。

データの取り扱い

アカウント情報、未読数、設定、取得状態はChrome内に保存します。未読数はGmailのAtomフィードから取得し、開発者のサーバーへ送信しません。詳しくはプライバシーポリシーをご覧ください。

お問い合わせ

解決しない場合は、GitHub Issuesからご連絡ください。

Support

Gmail Unread Tracker

If unread counts are not showing, check the following steps.

Frequently asked questions

An account does not appear in the list

Sign in to the account in Chrome, open Gmail, and click “Track with extension” in the sidebar. Then select “Refresh now” on the Options page.

The badge shows “!” or the count does not update

Make sure you are signed in to Gmail and select “Refresh now” on the Options page. You can choose an update interval of 1, 5, 15, 30, or 60 minutes. If the problem continues, check “Debug information” on the Options page.

How do I stop tracking an account?

Remove the account from the Options page. Uninstalling the Extension stops further processing.

Data handling

Account information, unread counts, settings, and fetch status are stored in Chrome. Unread counts are retrieved from Gmail's Atom feed and are not sent to a developer-operated server. See the Privacy Policy for details.

Contact

If these steps do not resolve the problem, contact us through GitHub Issues.
