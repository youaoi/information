プライバシーポリシー

最終更新: 2026年9月23日

Gmail Unread Tracker（以下「本拡張機能」）は、ログイン済みのGmailアカウントの未読メール件数をChromeのバッジとGmail画面に表示する拡張機能です。本ポリシーは、本拡張機能が処理する情報とその取り扱いを説明します。

処理する情報

本拡張機能は、機能の提供に必要な範囲で次の情報を処理します。

  • Gmailアカウント情報: ユーザーが追跡対象として登録したGmailアカウントのメールアドレス、アカウントの表示順、メインアカウントと合算対象の設定を処理します。代理アクセスの登録では、代理アカウントのメールアドレスとGmail上の識別情報も処理します。
  • 未読件数: GmailのAtomフィードから未読件数を取得し、アカウントごとの件数、合算件数、最終更新時刻、取得状態を表示します。
  • Gmail画面の情報: Gmail画面に追跡ボタンやラベル別の未読表示を追加するため、表示中のアカウント識別情報、ラベル名、未読表示を読み取ります。
  • 設定と診断情報: 未読件数の取得間隔、取得結果、HTTPステータス、取得時刻などをChromeのローカルストレージに保存します。

利用目的

  • Gmailアカウントの未読件数を定期的に取得して拡張機能のバッジへ表示するため
  • Gmail画面にアカウント追跡ボタンとラベル別の未読表示を追加するため
  • ユーザーが選択したアカウントの未読件数を合算し、ポップアップとオプション画面に表示するため
  • 取得失敗の状態を表示し、ユーザーが問題を確認できるようにするため

Gmailとの通信

本拡張機能は、ユーザーがChromeでログインしているGmailのセッションを使い、mail.google.com のAtomフィードへHTTPSで通信します。この通信は未読件数の取得に必要なもので、開発者が運用するサーバーを経由しません。Gmailの認証情報やCookieを本拡張機能が読み取ったり、開発者へ送信したりすることはありません。

取得しない情報

本拡張機能は、次の情報を機能の目的に利用しません。

  • メール本文、添付ファイル、連絡先の内容
  • 広告識別子、広告プロファイル、行動分析データ
  • クラッシュレポートや利用状況分析を目的としたデータ

第三者との共有

本拡張機能は、処理した情報を開発者のサーバーや広告事業者などの第三者へ送信、販売、共有しません。情報は、Gmailの未読件数を表示するという単一の目的に必要な範囲でのみ使用します。

保存と削除

設定、追跡対象アカウント、未読件数、取得状態はChromeのローカルストレージに保存されます。オプション画面から追跡対象アカウントを削除できます。本拡張機能をChromeからアンインストールすると、保存されていたローカルデータはChromeの管理に従って削除されます。

ユーザーの選択

  • Gmailのサイドバーから、追跡するアカウントをユーザーが選択できます。
  • オプション画面から、追跡対象、メインアカウント、合算対象、取得間隔を変更できます。
  • 本拡張機能をアンインストールすることで、以後の情報処理を停止できます。

ポリシーの変更

機能や法令への対応に伴い、本ポリシーを更新することがあります。変更後の内容はこのページに掲載し、最終更新日を更新します。

Privacy Policy

Last updated: September 23, 2026

Gmail Unread Tracker (the “Extension”) displays unread Gmail counts in the Chrome extension badge and on Gmail pages. This policy explains what information the Extension processes and how it is handled.

Information Processed

The Extension processes the following information only as needed to provide its features:

  • Gmail account information: The email address, display order, primary-account setting, and aggregate-account setting for Gmail accounts that the user chooses to track. For delegated access, the Extension also processes the delegated account email address and Gmail identifier needed to access that mailbox.
  • Unread counts: Unread counts from Gmail Atom feeds, including per-account counts, aggregate counts, last-update time, and fetch status.
  • Gmail page information: The account identifier, label names, and unread indicators needed to add tracking controls and label-level unread indicators to Gmail pages.
  • Settings and diagnostics: The polling interval, fetch results, HTTP status, and timestamps stored in Chrome local storage.

Purposes of Use

  • Periodically retrieve Gmail unread counts and display them in the extension badge
  • Add account tracking controls and label-level unread indicators to Gmail pages
  • Aggregate the unread counts selected by the user and display them in the popup and Options page
  • Show fetch failures so that the user can check the problem

Communication with Gmail

The Extension uses the Gmail session in which the user is signed in to communicate with Atom feeds on mail.google.com over HTTPS. This communication is required to retrieve unread counts and does not pass through a developer-operated server. The Extension does not read or send Gmail authentication credentials or cookies to the developer.

Information Not Used

The Extension does not use the following information for its purpose:

  • Email bodies, attachments, or contact contents
  • Advertising identifiers, advertising profiles, or behavioral analytics
  • Data for crash reporting or usage analytics

Data Sharing

The Extension does not send, sell, or share processed information with the developer’s servers, advertisers, or other third parties. Information is used only as necessary for the single purpose of displaying Gmail unread counts.

Storage and Deletion

Settings, tracked accounts, unread counts, and fetch status are stored in Chrome local storage. The user can remove tracked accounts from the Options page. Uninstalling the Extension removes locally stored data according to Chrome’s behavior.

Your Choices

  • The user chooses which accounts to track from the Gmail sidebar.
  • The user can change tracked accounts, the primary account, aggregate accounts, and the polling interval from the Options page.
  • Uninstalling the Extension stops further processing.

Changes to This Policy

This policy may be updated when features or legal requirements change. The updated version will be posted on this page with a new date.
