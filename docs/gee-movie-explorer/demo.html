Neon after rain

MP4のサンプル動画。Gee Movie Explorerで保存候補として検出できます。

アプリでの審査手順

  1. Gee Movie Explorerを起動します。
  2. このページのHTTPS URLをアドレス欄へ入力します。
  3. ページ読み込み後、動画検出・保存ボタンをタップします。
  4. 「Neon after rain」のMP4候補を確認し、保存します。
  5. 「保存動画」を開き、保存済み動画を再生します。
  6. 保存完了後に機内モードをオンにすると、元ページへ接続せず再生できます。

For App Review

Gee Movie Explorer is a minimal iOS browser that lets users explicitly select web videos, save them on the device, and play completed downloads offline.

  1. Launch Gee Movie Explorer.
  2. Enter this page's HTTPS URL.
  3. Tap the media detection and save button.
  4. Select the “Neon after rain” MP4 candidate and save it.
  5. Open Saved Videos and play the completed download.
  6. After the download completes, enable Airplane Mode to verify offline playback.

No login, payment, subscription, personal information, or special device permission is required. The app does not bypass DRM or access controls.
