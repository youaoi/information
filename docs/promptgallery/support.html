よくある質問

写真を追加できない

端末の「設定 > アプリ > Prompt Gallery」で写真へのアクセスが許可されているか確認してください。許可後、アプリを再起動してお試しください。写真なしのプロンプトだけを保存することもできます。

翻訳が使えない

Composer の翻訳は任意機能です。設定画面に OpenAI API キーを保存したうえで、Composer から翻訳を実行してください。キーは端末の Keychain にのみ保存されます。利用料は OpenAI のアカウントに課金されます。

データはどこに保存されますか

プロンプト、タグ、お気に入り、画像コピー、Composer の履歴はすべてこの端末内に保存されます。Prompt Gallery 側のサーバーやアカウントはありません。アプリを削除すると端末内のデータも削除されます。

Composer の履歴が残らない

Composer のセッション履歴は直近5件までです。クリップボード履歴は別管理です。端末を変更したりアプリを削除したりすると履歴は引き継がれません。

画像のない項目を開くと別画面になる

画像がない項目はギャラリービューアではなく、追加・編集用の画面が開きます。画像付きの項目はギャラリービューアで表示されます。

FAQ

I cannot add a photo

Go to Settings > Apps > Prompt Gallery on your device and make sure Photos access is allowed. Restart the app after granting permission. You can also save a prompt without a photo.

Translation does not work

Composer translation is optional. Save an OpenAI API key in Settings, then run translation from Composer. The key is stored only in this device’s Keychain. OpenAI usage may incur charges on your OpenAI account.

Where is my data stored?

Prompts, tags, favorites, image copies, and Composer history stay on this device. There is no Prompt Gallery account or server. Uninstalling the app removes on-device data.

Composer history disappeared

Composer session history keeps the latest 5 sessions. Clipboard history is stored separately. History is not synced if you change devices or delete the app.

Opening an item with no image shows a different screen

Items without an image open the add/edit prompt screen instead of the gallery viewer. Items with an image open in the gallery viewer.
