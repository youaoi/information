プライバシーポリシー

最終更新: 2026年8月

Prompt Gallery（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の取り扱いに細心の注意を払います。本ポリシーは、本アプリが取得・利用する情報とその目的を説明します。

収集する情報

本アプリが収集・処理する情報は以下のとおりです。

  • ギャラリーデータ: プロンプト本文、タグ、お気に入り、作成日時をデバイス内（SwiftData）に保存します。アカウントは作成せず、本アプリ運営者のサーバーへ送信することはありません。
  • 写真: 写真を選んだ場合、Photos から原本を削除しても残るよう、アプリ内ストレージへコピー（原寸とサムネイル）を保存します。翻訳などテキスト送信を伴う機能を使わない限り、写真は外部へ送信されません。
  • Composer の履歴: 直近の Composer セッション（最大5件）とクリップボード履歴をデバイス内（UserDefaults）に保存します。
  • 任意の翻訳: Composer の翻訳は任意です。ご自身の OpenAI API キーを設定画面で保存し、翻訳を実行した場合のみ、翻訳対象のプロンプト本文が OpenAI へ送信されます。API キーはデバイスの Keychain に保存されます。本アプリ運営者がキーやプロンプトを受け取るサーバーはありません。

収集しない情報

  • ユーザーアカウント・個人識別情報
  • 広告識別子・トラッキングデータ
  • クラッシュレポート・利用状況の分析データ

情報の共有

本アプリは、広告や分析のためにユーザーのデータを第三者と共有・販売・提供することはありません。

任意の翻訳を実行した場合、翻訳対象のテキストは OpenAI へ送信されます。OpenAI による取り扱いは OpenAI の方針と、ご利用の OpenAI アカウントに従います。写真は翻訳リクエストに含めません。

データの保存と削除

ギャラリーデータと画像はデバイス内にのみ保存されます。API キーは設定画面から削除できます。アプリをアンインストールすると、デバイス内に保存されたデータは削除されます。

お問い合わせ

プライバシーに関するご質問は、Twitter からお願いします。

Privacy Policy

Last updated: August 2026

Prompt Gallery ("the App") respects your privacy. This policy describes what information the App collects and how it is used.

Information Collected

  • Gallery data: Prompt text, tags, favorites, and creation dates are stored on this device (SwiftData). The App does not create an account and does not send this data to a developer-operated server.
  • Photos: When you choose a photo, the App saves a copy (original and thumbnail) in local storage so it remains available even if you delete the original from Photos. Photos are not uploaded unless you later use a feature that sends text to a service you configure.
  • Composer history: Recent Composer sessions (up to 5) and clipboard history are stored on-device (UserDefaults).
  • Optional translation: Composer translation is optional. If you save your own OpenAI API key in Settings and run a translation, the prompt text is sent to OpenAI. The API key is stored in this device’s Keychain. The App does not receive your key or prompt text on any developer-operated server.

Information Not Collected

  • User accounts or personal identifiers
  • Advertising identifiers or tracking data
  • Crash reports or analytics

Data Sharing

The App does not share, sell, or provide your data to third parties for advertising or analytics.

If you run optional translation, the prompt text is sent to OpenAI. OpenAI’s use of that data is governed by OpenAI’s policies and your OpenAI account. Photos are not included in translation requests.

Data Storage and Deletion

Gallery data and images are stored on-device only. You can remove the API key from Settings. Uninstalling the App removes data stored on the device.
